**English**: a Rust GUI library that renders the Windows 11 Fluent look identically on Windows,
Linux, macOS and Android, with signal-based reactivity and tooling for AI agents (headless
screenshots, widget tree, lint, MCP server). It also ships a terminal widget, remote files and
user-space VPN clients. → [Read the documentation](docs/en/README.md)

**Português**: biblioteca de interface em Rust com o visual Fluent do Windows 11, idêntica no
Windows, no Linux, no macOS e no Android, com estado reativo e ferramentas para agentes de IA
(capturas sem janela, árvore de widgets, lint, servidor MCP). Traz também um terminal, arquivos
remotos e VPNs que rodam sem administrador. → [Leia a documentação](docs/pt-BR/README.md)

# Code of conduct

Tomni UI adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: treat people with respect, accept constructive criticism, focus on what is best for
the community, and don't tolerate harassment, personal attacks or discriminatory language, in
issues, pull requests, discussions or any other project space.

The maintainers may remove comments, commits, code and issues that don't follow this code, and
ban anyone who persists in such behavior.

To report an incident, use GitHub's own "Report content" link on the comment or issue, or
contact the maintainers through the [TirechCorp](https://github.com/TirechCorp) organization
profile. Every report is handled confidentially.

# Código de conduta

O Tomni UI adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate as pessoas com respeito, aceite críticas construtivas, foque no que é melhor
para a comunidade e não tolere assédio, ataques pessoais ou linguagem discriminatória, em
issues, pull requests, discussões ou qualquer outro espaço do projeto.

Quem mantém o projeto pode remover comentários, commits, código e issues que não sigam este
código, e afastar quem insistir no comportamento.

Para relatar um caso, use o link "Report content" do próprio GitHub no comentário ou na issue,
ou fale com quem mantém o projeto pelo perfil da organização
[TirechCorp](https://github.com/TirechCorp). Todo relato é tratado com sigilo.
